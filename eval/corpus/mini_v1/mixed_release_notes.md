# Release notes 2.4 / Заметки о выпуске 2.4

Version 2.4 adds CSV export and the --dry-run flag for the import command. Версия 2.4 также ускоряет импорт больших файлов примерно вдвое. Known issue: the progress bar may show 100 percent before the last file is written. Известная проблема: шкала прогресса может показать 100 процентов раньше, чем будет записан последний файл.
